# hashtagGirlBoss

A machine learning web application that predicts the outcomes of Major League Baseball games using historical performance data and statistical analysis.

## Project Overview

This project was developed as a collaborative group assignment, combining data science, machine learning, and web development to create an interactive platform for predicting MLB game outcomes. The application analyzes historical baseball statistics and team performance metrics to forecast game winners.

## Key Features

### Machine Learning Prediction Model
- Predictive model trained on historical MLB game data
- Statistical modeling to forecast game outcomes

### Interactive Web Interface
- User-friendly HTML interface for game predictions
- Input forms for selecting teams and game parameters
- Real-time prediction results display
- Visualization of prediction confidence and key factors

### Data Analysis
- Exploratory data analysis of MLB statistics
- Feature engineering and selection
- Data preprocessing and cleaning
- Statistical insights into factors influencing game outcomes

## Technologies Used

- **Python**: Core programming language for data analysis and modeling
- **Jupyter Notebooks**: Interactive development and analysis environment
- **HTML/CSS**: Web interface design and structure
- **Machine Learning Libraries**: scikit-learn, pandas, numpy for predictive modeling
- **Data Visualization**: matplotlib, seaborn for statistical graphics
